# Website Profil — Indana Aulia Rahma

Website profil pribadi dengan tema soft blue, elegan, dan responsif. Dibuat menggunakan HTML, CSS, dan JavaScript biasa sehingga bisa langsung di-host di GitHub Pages.

## Cara menjalankan
1. Ekstrak file ZIP.
2. Buka folder `indana-portfolio`.
3. Klik dua kali `index.html` untuk melihat website di browser.

## Cara upload ke GitHub Pages
1. Buat repository baru di GitHub, misalnya `profil-indana`.
2. Upload semua isi folder ini (bukan folder ZIP-nya) ke repository.
3. Buka **Settings → Pages**.
4. Pada bagian **Build and deployment**, pilih **Deploy from a branch**.
5. Pilih branch `main` dan folder `/ (root)`, lalu klik **Save**.
6. Tunggu beberapa saat. Website akan tersedia melalui alamat GitHub Pages yang ditampilkan di halaman tersebut.

## Catatan
- Foto galeri memakai gambar ilustrasi dari Unsplash dan memerlukan koneksi internet.
- Ganti URL gambar di `index.html` jika ingin memakai foto hasil masakan sendiri.
- Informasi kontak dan alamat akan terlihat publik jika website dipublikasikan. Pertimbangkan untuk menyamarkan nomor HP atau alamat sebelum mengunggahnya.
